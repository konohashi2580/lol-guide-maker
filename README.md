# LoL 解説画像メーカー

League of Legends のチャンピオン解説画像（左サイドバー＋右セクション積み、1200×1738）を、ブラウザだけで作れる静的Webアプリです。

- データ（チャンピオン／スキル／ルーン／アイテム／サモナースペルの日本語名とアイコン）は、実行時に Riot Games 公式の **Data Dragon（ja_JP）** から取得します
- 画像は公式CDNから読み込むため、生成されるPNGには公式アイコン・スプラッシュがそのまま入ります
- 入力内容はブラウザの localStorage に自動保存され、再訪時に復元されます
- 初期表示（保存データが無い場合）はレルTOPのサンプルデータになっています。そのまま書き換えて使えます（保存済みの入力がある場合はそちらが優先されます）
- サーバー・ビルド工程は不要です。このフォルダのファイルをそのまま置くだけで動きます

## 使い方

1. ページを開く（Data Dragon の読み込みに少し時間がかかります）
2. チャンピオンを選ぶ（名前で検索できます）。肩書き・難易度・スキル名・パッシブ名は自動で入ります
3. ロール、キャッチコピー、サモナースペル、スキルオーダー、ルーン、アイテム、強み・弱み、コンボ、勝つための3カ条、合言葉を入力する
   - アイテムは名前で検索して選べます（候補が表示されます）。アイテムビルドは3行構成で、1行に最大6個まで横一列に入ります（個数に応じて間隔が自動で詰まります）
   - スプラッシュの切り出し位置は「スプラッシュ横位置」スライダーで調整できます
   - アクセントカラーはカラーピッカーで変更できます
4. 右側のプレビューで確認し、「PNGをダウンロード」で 1200×1738 の画像を保存します

## GitHub Pages で公開する手順

### 1. リポジトリを作る

1. GitHub にログインし、右上の「＋」→「New repository」
2. Repository name を入力（例：`lol-guide-maker`）
3. 「Public」を選び、「Create repository」

### 2. ファイルを置く

このフォルダの中身を、リポジトリのルート（最上位）にそのままアップロードします。

- 必要なファイル：`index.html` / `style.css` / `app.js`（`README.md` は任意）
- Web画面から上げる場合：リポジトリのページで「Add file」→「Upload files」→ ファイルをドラッグ＆ドロップ →「Commit changes」
- git を使う場合：

```bash
git clone https://github.com/<ユーザー名>/lol-guide-maker.git
cd lol-guide-maker
# このフォルダのファイルをここにコピーしてから
git add .
git commit -m "LoL解説画像メーカーを追加"
git push origin main
```

### 3. Pages を有効化する

1. リポジトリの「Settings」→ 左メニューの「Pages」
2. 「Build and deployment」の Source で「Deploy from a branch」を選ぶ
3. Branch で `main` と `/ (root)` を選び、「Save」
4. 数分待つと、ページ上部に公開URLが表示されます

公開URLの形式：`https://<ユーザー名>.github.io/lol-guide-maker/`

### 4. 更新したいとき

`index.html` / `style.css` / `app.js` を差し替えて push（または再アップロード）すれば、数分で反映されます。
その際は `index.html` 内のアセット参照の `?v=` の番号も必ず上げてください（例：`app.js?v=4` → `app.js?v=5`）。ブラウザや GitHub Pages のキャッシュで新旧ファイルが混ざって読み込まれるのを防ぐためです。

## 注意

- 利用にはインターネット接続が必要です（Data Dragon からデータと画像を取得するため）
- パッチ表記は初期値 26.22 です。テキスト欄で自由に書き換えられます（画像データ自体は Data Dragon の最新バージョンを使用します）
- 入力内容の保存先は使っているブラウザの中だけです。他のブラウザ・端末とは共有されません
